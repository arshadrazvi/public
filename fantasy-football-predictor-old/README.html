NFL Fantasy Analytics

Fantasy Football Weekly Predictor

A simple full-stack application that analyzes NFL player performance, learns from recent trends, and produces weekly fantasy-football projections with easy-to-understand ranges and historical accuracy checks.

Get Started How It Works

What this project does

Collects NFL data

Loads weekly player statistics from nflverse through the nflreadpy package.

Analyzes player trends

Looks at recent games, season averages, target trends, carry trends, and player efficiency.

Predicts fantasy output

Uses machine learning to estimate player statistics and converts those estimates into fantasy points.

How the projection works

The model does not guess fantasy points directly. It predicts football statistics first, then calculates the fantasy score from those projected stats.

Player statistics predicted

Passing yards, passing touchdowns, interceptions, rushing yards, rushing touchdowns, receptions, receiving yards, and receiving touchdowns.

Fantasy scoring

The current version uses full-PPR scoring, but the architecture can later support standard, half-PPR, and custom league settings.

Built-in backtesting

The app can test itself against historical NFL weeks. When predicting Week 10, the model only uses information available through Week 9.

MAE

Average size of the prediction error.

RMSE

Penalizes larger misses more heavily.

Accuracy bands

Shows the percentage of predictions within ±2, ±4, and ±6 fantasy points.

Getting started

Open the project directory 
cd fantasy-football-predictor
Create a Python virtual environment 
python3 -m venv .venv
source .venv/bin/activate
Install the required packages 
pip install -r requirements.txt
Start the application 
python run.py
Open the browser interface 
http://127.0.0.1:8000

API access

The application also provides a REST API and interactive Swagger documentation.

GET  /api/health
GET  /api/predictions
GET  /api/backtest
POST /api/refresh

Swagger documentation:

http://127.0.0.1:8000/docs

Important note about projections

Fantasy-football projections are estimates, not guarantees. NFL results can change because of injuries, coaching decisions, turnovers, substitutions, weather, and game flow. The projection should be used as decision support rather than as a promise of a player's final score.
